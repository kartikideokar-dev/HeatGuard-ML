# HeatGuard-ML

A machine learning-based heat-risk prediction system with a frontend interface and backend API.

## 📌 Project Overview

HeatGuard ML aims to estimate heat-related risk from relevant environmental and individual-level features. It combines a machine learning model with a web interface to make predictions accessible to users.

## ✨ Features

- Machine learning-based heat-risk prediction
- Web-based frontend interface
- Backend API integration
- Data exploration and model experimentation
- Prediction results displayed through the application

## 🛠️ Technology Stack

- **Machine Learning:** Python, scikit-learn, pandas, NumPy
- **Model Development:** Jupyter Notebook
